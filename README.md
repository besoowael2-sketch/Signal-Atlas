# SIGNAL ATLAS

An interactive, responsive cyber-awareness website built with semantic HTML, CSS, and vanilla JavaScript.

## Run locally
1. Extract the ZIP.
2. Open `index.html` in a modern browser.

No build step, package manager, API key, or backend is required.

## Features
- Distinctive dark editorial art direction with custom orbital SVG artwork.
- Responsive mobile navigation.
- Interactive simulated traffic chart with three selectable patterns.
- Expandable security field notes and linked threat primers.
- Copyable safety principle with feedback toast.
- Scroll reveal, active navigation, back-to-top control.
- Keyboard focus styling and reduced-motion support.
- No external runtime libraries. Google Fonts are optional; system fallbacks are included.

## Scope note
The chart uses illustrative, hard-coded sample data. It does not monitor devices, connect to networks, or provide real-time threat intelligence. This is an educational frontend concept.
