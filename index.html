03 / Field guide

Five notes for a safer digital life.

Open a note to explore a practical habit. These are general educational suggestions; follow your school or organization’s security policies where applicable.

FIELD MANUAL / REV. 1.0

Check the sender and destination before acting. If a message asks for a password, payment, or urgent action, contact the person or organization using a trusted channel you already know.

Use a reputable password manager to create unique passwords. Enable multifactor authentication when available, especially for email, cloud storage, and accounts that can reset other passwords.

Install operating-system, browser, and application updates from official channels. If you manage a shared device, follow the organization’s update process instead of bypassing it.

Grant apps only the access they need. Remove unused accounts and review sharing links periodically. Use standard accounts for everyday work where practical, keeping administrator access limited.

Keep important files in a reliable backup location and periodically check that you can restore them. A backup that has never been tested may not be useful when you need it.

END OF TRANSMISSION / BEGIN WITH CURIOSITY

Stay curious.
Stay deliberate.

Cybersecurity is not about fearing every signal. It is about learning enough to ask better questions, verify what matters, and make safer choices.
